# handoff

Фронтенд проекта handoff на React 19, TypeScript, Vite и Tailwind CSS 4.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```
npm install
npm run dev
```

По умолчанию приложение открывается на http://localhost:5173.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер с горячей перезагрузкой |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run preview` | локальный запуск собранной версии |
| `npm run lint` | проверка кода через oxlint |
